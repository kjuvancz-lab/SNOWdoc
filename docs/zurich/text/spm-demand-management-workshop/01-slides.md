Demand assessment explained
During the Screening phase the Demand stakeholders can assess the Metrics that are type assessment
The list of stakeholders can be manually defined for each Demands or automatically associated depends on the Demand portfolio. It's possible to define them in Project Administration > Settings > Stakeholders

on Self Service > My Assessment & Surveys

_Notes:_ NOTES: How to add an assessment metric: Navigates to Project Administration &gt; Settings &gt; Assessment Metric Categories. Click on New and creates a new assessment metric. Once the information is filled out, Click Save to stay on the record. ## Slide 54

The min and max values in calculating
The example below assumes X-Large was selected, which means a score of 8, but it’s not that simple…
If the min value is set to 1 and the max is set to 10, you will get 7.78 for size score instead of a rounded number 8. The calculation below explains: 
Min Value of 1 and Max of 10
X1 = a + ((X-Xmin) * (b-a)/(Xmax-Xmin))
X1 = 0 + ((8-1) * (10-0)/(10-1))
X1 = 0 + (7 * 10)/(9)
X1 = 7.78 (rounded to 2 digits)
Min Value of 0 and Max of 10
X1 = a + ((X-Xmin) * (b-a)/(Xmax-Xmin))
X1 = 0 + ((8-0) * (10-0)/(10-0))
X1 = 0 + (8 * 10)/(10)
X1 = 8.00 (rounded to 2 digits)
Best Practice is to use min value of 0 and max of 10

-  Risk (from Stakeholder assessments)
-  Value (Impact and Financial Return fields)

When the  Risk  and  Size  are high, the score of the Demand is low
