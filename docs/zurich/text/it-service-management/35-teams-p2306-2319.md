Example for using teams in Workforce Optimization for ITSM
Understand how you can manage your teams from a single location using an example.
A manager of IT Service Desk directly manages 3 teams. They are an additional manager of other
teams that they have visibility into although they don't directly report to them.
To analyze team performance, the manager:
1. Organizes the teams into groups called assignment groups. The teams either directly report to
the manager or the manager may have visibility into team performance.
2. Creates a KPI group with a set of indicators that matter most to measure the performance of
their assignment groups.
3. Adds all assignment groups that use the set of KPIs to the KPI group.
With this set up, the manager can effectively analyze the performance of the teams grouped by
KPI groups.
The manager can set up and use Teams by performing the following steps:
1. Create a KPI group
2. Add KPIs to that group
3. Add managers to assignment groups
4. Add assignment groups to the KPI group
5. Associate multiple KPI groups with one or more assignment groups.
6. Drill down into a KPI, agent, or an incident to analyze performance
Get an overview of how you can analyze team performance in this video. Use Teams to track
performance
For detailed information on how to setup and use Teams, see Teams.

Analyze the performance trends for your teams

Analyzing team performance using Teams in Workforce Optimization for ITSM
Use Teams to track and analyze performance trends for your teams from a single location.
You can monitor the trends for each agent within your team and compare your agents or team
members with one another. With Teams, you can identify skill gaps so that you can recommend
which skills are needed to coach your agents.
Organize your teams into assignment groups. You can add a set of key performance indicators
(KPIs) to help you measure team performance consistently across the groups.
For example, let's say that you manage the IT Service Desk unit. The unit contains multiple teams,
such as Hardware and Network Support. You can create a KPI group for the IT Service Desk unit
and then add Hardware and Network Support as assignment groups to this KPI group. Next,
you add a set of KPIs to the KPI group. With this data, you can measure the performance trends
across the Hardware and Network Support teams.
Also, an admin can associate multiple KPI groups with one or more assignment groups. For
example, let’s say that there are two KPI Groups:
• IT Service
• Operations
The IT Service KPI group comprises two assignment groups:
• IT Service Desk
• Deskside support
So, an admin can add one or more assignment groups already available in the IT Service KPI
group to the Operations KPI group. For example, Deskside support.
As the Deskside support assignment group is a part of both the KPI groups, it means one or more
KPI groups can be associated with one or more assignment groups.
