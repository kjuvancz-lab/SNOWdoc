# snow-doc-index

Contents map of the local ServiceNow documentation corpus (`C:\Users\q407593\SNOW Doc`, 24 files, 1.2 GB).

The corpus itself is not in this repo. `SNOW_Doc_contents_map.md` tells a chat session which file and which page range answers a question, so only those pages are read.

Regenerate the page tables with `pdftotext` when a document is replaced by a newer release.
